# Security

Report a vulnerability privately, through this repository's
[private vulnerability reporting](https://github.com/flw-beam/checkout-js/security/advisories/new):
the Security tab, then **Report a vulnerability**. Please do not open a public
issue, discussion or pull request about it.

Include what you found, the package and version, how to reproduce it, and what
someone could do with it. We will acknowledge the report, keep you informed while
we fix it, and credit you in the advisory unless you would rather we did not.

This covers the packages in this repository and the release assets built from
it. A problem with the checkout service itself, such as the hosted checkout page
or the API, can be reported the same way, and we will route it.

Never send real card numbers, secret keys, or other live credentials in a report.
Test-mode keys and the sandbox's test card numbers are enough to show a problem.
